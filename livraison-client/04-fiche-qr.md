# FICHE QR CODE — Mode d'emploi

## Pour le gérant

### Imprimer les QR codes
1. Ouvrez l'app Admin → **Utilisateurs** → **QR activation**
2. Le QR code s'affiche à l'écran
3. Faites une capture d'écran → imprimez
4. Plastifiez et collez sur chaque table

### Un QR code par table
Chaque table a son propre QR code qui pointe vers :
```
http://[adresse-du-restaurant]/?table=T1
http://[adresse-du-restaurant]/?table=T2
...
```

---

## Pour le client

1. Scannez le QR code sur la table avec votre téléphone
2. Le menu du restaurant s'affiche
3. Parcourez les plats → ajoutez au panier
4. Validez votre commande
5. La cuisine reçoit votre commande directement

**Pas besoin d'installer d'application !**

---

## Modèle de QR code à imprimer

```
┌─────────────────────────┐
│                         │
│   🍽️ [NOM DU RESTO]    │
│                         │
│   Scannez pour          │
│   commander !           │
│                         │
│   ██████████████████    │
│   ██             ██     │
│   ██  [QR CODE]  ██     │
│   ██             ██     │
│   ██████████████████    │
│                         │
│   Table T___            │
└─────────────────────────┘
```

Format recommandé : 10 cm × 10 cm, plastifié
