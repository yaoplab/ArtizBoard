# FICHE SUPPORT — Que faire si...

## ⚠️ Urgences

| Problème | Solution |
|---|---|
| **L'appli Admin ne s'ouvre plus** | Redémarrez le PC. Si le problème persiste, appelez le support. |
| **Les serveurs ne voient plus les commandes** | Vérifiez que le Wi-Fi fonctionne. Redémarrez les téléphones. |
| **Le site web est vide** | Vérifiez la connexion internet. Attendez 30 secondes, rafraîchissez. |
| **Erreur "Connexion refusée"** | Le serveur local est peut-être éteint. Vérifiez le PC principal. |

---

## 🔧 Problèmes courants

| Problème | Solution |
|---|---|
| **Mot de passe oublié** | Contactez le gérant pour réinitialiser |
| **Impossible d'ajouter un produit** | Vérifiez que vous êtes connecté en tant qu'Admin |
| **La photo ne s'upload pas** | Vérifiez la connexion internet. Réessayez avec une image plus petite. |
| **La commande n'apparaît pas en cuisine** | Rafraîchissez l'écran (bouton 🔄) |
| **QR code ne scanne pas** | Vérifiez l'éclairage. Essayez de saisir le code manuellement. |
