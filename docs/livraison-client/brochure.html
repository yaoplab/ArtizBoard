Guide Admin (Gérant)

Ce que vous pouvez faire depuis le PC du bureau.

1. Gérer votre catalogue

1

Ouvrez le menu Catalogue

Dans le menu de gauche, cliquez sur Catalogue.

2

Ajoutez une catégorie

Cliquez sur + dans la colonne de gauche. Donnez un nom (ex: "Entrées", "Plats", "Boissons").

3

Ajoutez un produit

Sélectionnez une catégorie, puis Ajouter un produit. Remplissez le nom, le prix (en FCFA), la description.

4

Ajoutez une photo

📷 Cliquez sur Uploader une photo pour illustrer le plat.

2. Gérer vos utilisateurs

1

Menu Utilisateurs

Cliquez sur Utilisateurs dans le menu.

2

Ajouter un employé

Cliquez sur + Ajouter. Saisissez le nom, email, rôle (serveur, cuisinier...).

3

Générer le QR code

Cliquez sur l'icône QR. Le code s'affiche à l'écran. Scannez-le avec le téléphone de l'employé.

3. Apparence du site web

Menu Établissement → Apparence. Choisissez un template dans le menu déroulant. Les couleurs, polices et images changent immédiatement sur votre site web.

Guide Serveur & Cuisinier

Utilisation de l'application sur le téléphone.

📋 Prendre une commande

1. Onglet Commander
2. Choisissez la table
3. Ajoutez les plats → Valider

👀 Suivre les commandes

1. Onglet En cours
2. 🟢 Prêt → Servir ✓

💰 Encaisser

1. Onglet Encaisser
2. Choisissez la commande → Payer

🍳 Cuisine (KDS)

1. Onglet Cuisine
2. Flèche → pour avancer
3. Colonnes : En attente | En préparation | Prêt

Astuces

🔄 Rafraîchir : le bouton 🔄 recharge les commandes.
📱 Plusieurs téléphones : chaque serveur a son téléphone, tous voient les mêmes commandes.
🔊 Son : un bip retentit quand une nouvelle commande arrive en cuisine.

QR Code & Dépannage

Pour vos clients

📱
Scannez pour commander !
1. Ouvrez l'appareil photo de votre téléphone
2. Visez le QR code sur la table
3. Le menu s'affiche → commandez directement
Pas d'application à installer !

Que faire si...

ProblèmeSolution
L'appli Admin ne s'ouvre pasRedémarrez le PC. Si le problème persiste, appelez le support.
Les serveurs ne voient plus les commandesVérifiez que le Wi-Fi fonctionne. Redémarrez les téléphones.
Le site web est videVérifiez la connexion internet. Rafraîchissez la page.
Mot de passe oubliéContactez le gérant pour réinitialiser.
La commande n'apparaît pas en cuisineAppuyez sur le bouton 🔄 pour rafraîchir.
QR code ne scanne pasVérifiez l'éclairage. Saisissez le code manuellement.
⚠️ IMPORTANT
En cas de panne de courant ou de Wi-Fi, l'application continue de fonctionner sur le réseau local. Les commandes sont sauvegardées et synchronisées dès que la connexion revient.
