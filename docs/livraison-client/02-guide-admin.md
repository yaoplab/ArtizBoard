## Ce que vous pouvez faire

### Gérer vos produits
1. Cliquez sur **Catalogue** dans le menu de gauche
2. À gauche : vos catégories (Entrées, Plats, Boissons...)
3. Au milieu : vos produits
4. À droite : le détail du produit sélectionné
5. Bouton **+** : ajouter une catégorie
6. Bouton **Ajouter un produit** : créer un nouveau plat

### Modifier un produit
1. Cliquez sur le produit → ses infos s'affichent à droite
2. Cliquez sur **Modifier**
3. Changez le nom, le prix, la description
4. 📷 **Uploader une photo** pour ajouter une image
5. Cliquez sur **Enregistrer**

### Gérer vos utilisateurs (serveurs, cuisiniers)
1. Cliquez sur **Utilisateurs**
2. **+ Ajouter** : créer un compte pour un employé
3. **QR** : générer un code pour activer son téléphone
4. Sur le téléphone de l'employé : ouvrir ArtizBoard Staff → scanner le QR

### Voir vos ventes
1. Cliquez sur **Dashboard** pour les chiffres du jour
2. Cliquez sur **Rapports** pour exporter en CSV ou PDF

### Changer l'apparence du site web
1. Cliquez sur **Établissement** → onglet **Apparence**
2. Choisissez un template dans le menu déroulant
3. Cliquez sur **Enregistrer**
4. Le site web change immédiatement

### Ajouter des pages au site (À Propos, Contact...)
1. Cliquez sur **Établissement** → onglet **Pages**
2. **Ajouter une page** → donnez un titre, écrivez le contenu
3. La page apparaît sur votre site dans la section "À Propos"
