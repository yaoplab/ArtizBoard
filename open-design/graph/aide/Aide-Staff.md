# Guide Staff — ArtizBoard

## Connexion
1. Ouvrir l'app Staff (APK ou navigateur)
2. Scanner le QR code affiché par l'Admin
3. Ou saisir le code d'activation manuellement

## Prendre une commande
1. Sélectionner la table (T1, T2, Comptoir...)
2. Parcourir les catégories → ajouter des plats au panier
3. Valider la commande → envoyée en cuisine

## Suivi des commandes
- Onglet **En cours** → voir le statut de chaque commande
- **Servi ✓** → marquer comme livré

## Encaissement
- Onglet **Encaisser** → voir les commandes à payer
- Sélectionner le moyen de paiement → valider

## Cuisine (KDS)
- Onglet **Cuisine** → kanban des commandes
- Glisser de "En attente" → "En préparation" → "Prêt"
